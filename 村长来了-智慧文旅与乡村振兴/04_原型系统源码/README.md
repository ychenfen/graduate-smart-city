# 「村长来了」原型系统

面向县域乡村景区的 AI 数字人导览与文旅运营原型。本目录为参赛团队原创的原型系统源代码，作为项目说明书中软件类作品的证明材料。

## 运行方式

双击 `index.html`，用 Chrome / Edge / Safari 打开即可。无需安装、无需联网、不调用任何外部接口。

- 若电脑能访问 Google Fonts，会加载展示字体；不能访问时自动回退到系统楷体和黑体，不影响功能。
- “村长开口说话”使用浏览器内置的语音合成（Web Speech API）。Windows 和 macOS 自带中文语音；如果没有中文语音，会只显示文字，嘴型动画照常。

## 功能模块

| 模块 | 原型实现 | 正式版实现路线 |
| --- | --- | --- |
| 数字人村长 | SVG 卡通形象，说话时嘴型随语音开合，眨眼与轻微摆动 | Live2D / 3D 形象，基于音素的口型驱动 |
| 语音导览问答 | 本地村落知识库（13 类意图）+ 关键词加权匹配 | 本地部署的量化大模型 + 检索增强（RAG），方言语音识别 |
| 拍照识物 | 4 类示例景物；上传照片按画面主色调匹配 | 本地部署的轻量视觉模型，对村内景物做小样本微调 |
| AIGC 明信片 | Canvas 程序化生成山景、梯田、古樟剪影与邮戳，写入游客“今日足迹” | 文生图模型按村落风格出图，扫码领取 |
| 村委运营看板 | 热点问题随现场提问实时累加；客流、景点热度为示例数据 | 汇聚问答日志、客流计数、消费数据，生成分流与营销建议 |

## 推荐演示顺序（约 2 分钟）

1. 打开页面，村长自我介绍。
2. 点击“帮我排个一日游”，展示语音、口型和路线推荐。
3. 切到“拍照识物”，点击“千年古樟”。
4. 切到“生成明信片”，输入名字后生成，足迹会包含刚才聊到的景点。
5. 切到“村委运营看板”，展示热点问题柱状图随本场提问增长。
