# 「村长来了」原型系统

面向县域乡村景区的 AI 数字人导览与文旅运营原型。本目录为参赛团队原创的原型系统源代码与测试脚本，作为软件类作品的证明材料。

## 运行方式

双击 `index.html`，用 Chrome / Edge / Safari 打开即可（`engine.js` 需与它放在同一目录）。无需安装、无需联网、不调用任何外部接口。

- 能访问 Google Fonts 时加载展示字体，否则自动回退到系统楷体和黑体，不影响功能。
- “开口说话”使用浏览器内置的语音合成。没有中文语音时只显示文字，嘴型动画照常。

## 目录

| 文件 | 内容 |
| --- | --- |

| `test/eval.js` | 测试脚本，输出 `test/results.json` |
| `test/ablation.js` | 消融实验脚本，输出 `test/ablation.json` |

## 问答引擎

1. **口语归一**：把“小朋友、早点、无线网”等说法扩展为知识库中的标准词。
2. **混合检索**：字符二元组 BM25 与关键词整词命中加权。
3. **置信度拒答**：综合得分强度、领先幅度和问题覆盖度，低于阈值 0.35 时如实拒答，并把问题记入村委“待补充”清单。
4. **多轮追问**：问“那里怎么去”“几点开门”时自动结合上一轮的景点。
5. **知识闭环**：村委在“村委知识库”页补充答案后即时重建索引，游客换种说法也能问到。

## 推荐演示顺序（约 2 分钟）

1. 点“帮我排个一日游”“李氏宗祠有什么看头”，再点“几点开门？”，展示资料来源和多轮追问。
2. 点“村里有充电桩吗？”，村长如实拒答。
3. 切到“村委知识库”，给这条问题补充答案。
4. 回到聊天输入“电动车哪里能充电”，村长马上答上。
5. 依次展示拍照识物、足迹明信片和运营看板。

演示用村落“云溪村”及其景点、人物、资料来源均为虚构。
