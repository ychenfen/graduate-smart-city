# v2 变更记录（2026-10-22）

基线：提交 `7369e14`（v1，24 项测试）。v2 在其上做增量优化；**默认选优逻辑和七案例既有数值未改**，由 `tests/v2.test.js` 对 `tests/fixtures/v1_core.json` 的逐项回归锁定，因此 v1 的 PPTX、解说视频和冻结 ZIP 中的数值仍然有效。

## 发现的问题（v1）

1. **选优乐观偏差**：在同一批抽样上先算可靠度再挑“最优”，被选方案的可靠度会被高估。默认种子下 C1 选优时 86.5%，独立复验 83.8%，**低于 85% 目标**，v1 材料中“模型内达成”的表述在该案例上不稳。多种子下偏差均值很小（约 0.4 个百分点），但 C1 在 12 个种子中仅 75% 通过独立复验。
2. 服务端：静态文件路径仅用 `startsWith(ROOT)`，同前缀目录可绕过；超限请求体会让请求挂起不返回；`Access-Control-Allow-Origin: *` 使任意网页可向本地服务写入反馈状态；schema 未在运行时强制。
3. 课题要求的雷达图对比、可解释性、环保约束在 v1 中缺失或仅有文字描述；浏览器交互未验收。

## 新增与修改

| 方面 | 内容 |
|---|---|
| 复验 | `recommended.validation`：独立种子、4000 次抽样、区间、选优偏差、是否达标（含经验基线） |
| 选优 | `selection: "validated"`：按成本升序在独立噪声上复算候选，首个通过者胜出；最终复验另用一组噪声。默认仍为 `point` |
| 约束 | `carbonCapYr` 年均碳排上限（环保约束），无解时统计 `carbonCut` |
| 解释 | `explain`：对 7 个组成维度做精确 Shapley（128 联盟），效率性有测试；解释对象是机理先验预测式 |
| 对比 | `radar`：6 轴（联合可靠度、短板达标率、寿命、年值经济性、低碳、施工容错） |
| 图谱 | `engine/graph.js`：由知识库与预测式导出的材料—指标—规则图；improvers / profile / drivers 查询；规则目录与引擎剔除原因由测试校验一致 |
| 校验 | `engine/validate.js` 按 schema 逐字段校验，接口返回字段级错误 |
| 服务 | 修复路径穿越与超限挂起；CORS 仅放行同源回环来源；新增 `/graph*`、`/validate`、`/feedback/reset`、`GET /feedback`；安全响应头 |
| 界面 | v2.0：雷达图、Shapley 页签、图谱查询、碳排与抽样次数输入、稳健选优开关、独立复验行、导出 JSON、`aria-live`、打印样式 |
| 验证 | 测试 24→36 项；`tools/ui_check.py` 无头 Chromium 31 项检查（桌面+移动视口）；`tools/robustness.js` 多种子实验 |
| 文档 | 02 说明书、04 技术交接、05 七案例报告更新（`deliverables/文档_v2/`，DOCX+PDF）；`tools/freeze_package.py` 支持版本名 |

## 仍未解决（不要在材料中暗示已解决）

- 材料性能、费用、碳排、寿命仍为待标定先验；规范门槛未逐条核对现行条文；城市气候为近似值。
- 复验和多种子只反映抽样误差与选优偏差，不含先验或模型结构误差。
- Shapley/关联图解释的是机理先验公式，不是数据驱动模型；不能称 SHAP/LIME 或实测知识图谱。
- C2、C5 在所有种子上都达不到目标可靠度。
- 10 页 PPTX 与解说视频沿用 v1，未展示 v2 新能力；其生成依赖 Codex artifact-tool 运行时与 macOS 语音，本环境无法重建。
- 界面检查为无头 Chromium，非真机、读屏或用户测试。
- 团队名、作品编号、成员及匿名处理方式仍待确认；未向比赛官网提交。
