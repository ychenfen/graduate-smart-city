# 养护决策系统 ⇄ 材料推荐引擎 接口规范 v0.1

推荐引擎以 HTTP/JSON 提供服务。养护决策系统只需输出**场景参数**，即可获得**材料方案参数**；两侧独立开发、独立迭代。
完整的字段定义与在线调试见服务启动后的 `/docs`（OpenAPI 自动生成，来源 `smartmix/schemas.py`）。

## 1. 场景参数 `MaintenanceScenario`（养护决策系统 → 引擎）

| 字段 | 类型 | 说明 |
|---|---|---|
| `climate.hot_month_max` / `extreme_min` / `annual_rain` | number | 最热月平均最高气温 ℃、年极端最低气温 ℃、年降雨量 mm；引擎按 JTG F40 自动分区 |
| `high_zone` / `low_zone` / `rain_zone` | int | 也可直接给分区编号（1–3 / 1–4 / 1–4），与 `climate` 二选一 |
| `traffic` | 轻/中等/重/特重/极重 | 设计交通荷载等级 |
| `layer` | 上面层/中面层/下面层 | 养护层位 |
| `thickness_cm` | number | 铺筑厚度，约束可选级配 |
| `structure` | semi_rigid / flexible / bridge_deck | 半刚性基层 / 柔性基层 / 桥面铺装 |
| `special` | none / long_grade / intersection | 一般路段 / 长大纵坡 / 交叉口 |
| `distress[]` | `{type, severity}` | type: rutting, thermal_crack, fatigue_crack, reflective_crack, water_damage, skid, none；severity: 轻/中/重 |
| `method` | string | 养护决策给出的工法（记录用） |
| `constraints` | object | `cost_priority`、`carbon_priority`（低/中/高），`allow_rap`，`budget_max`（元/t） |

## 2. 方案参数（引擎 → 养护决策系统）

`POST /api/v1/recommend` 返回：

| 字段 | 说明 |
|---|---|
| `requirements.targets` | 6 项性能目标值、是否硬性、推导依据 |
| `requirements.weights` / `priority` / `trace` | 权重、优先级排序、推导轨迹 |
| `search` | 候选数、规则过滤后数、保守达标数、被排除原因 |
| `candidates[]` | 推荐方案（见下） |
| `pareto[]` | 性能—年均成本—年均碳排 Pareto 前沿点 |
| `baselines[]` | 请求中附带的对比方案的同口径评估 |

每个 `candidate`：

| 字段 | 说明 |
|---|---|
| `mix` | 机读配方（可原样回传 `/evaluate` 做微调） |
| `label` | 人读配方名称 |
| `formula` | PG 分级、油石比、改性剂与掺量、助剂、RAP |
| `predictions` | 6 项性能：`mean` / `low` / `high` |
| `checks[]` | 逐项：目标、预测、75% 保守值、是否达标、归一化裕度 |
| `economics` | 元/t、元/m²、kgCO₂e/t、预期寿命、年均成本、年均碳排 |
| `construction` | 拌和温度窗口、压实度敏感性、最低达标压实度、施工要点 |
| `reasons` / `explanations` / `kg_paths` | 推荐理由、各因素贡献（先验 + SHAP）、知识图谱推理路径 |

## 3. 其他接口

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/v1/requirements` | 只做场景 → 性能需求映射 |
| POST | `/api/v1/evaluate` | 评估任意（人工微调后的）方案，返回结构同 `candidate` |
| POST | `/api/v1/predict` | 批量性能预测 |
| GET | `/api/v1/kg` | 知识图谱节点、关系与规则 |
| POST | `/api/v1/feedback/lab` | 追加室内试验记录（可部分缺测），可选立即重训 |
| POST | `/api/v1/feedback/field` | 追加路用寿命记录，更新寿命校正系数 |
| POST | `/api/v1/model/retrain` | 手动重训 |
| GET | `/api/v1/model` | 模型版本、样本构成、噪声水平、寿命校正 |

## 4. 示例

```bash
curl -X POST http://127.0.0.1:8000/api/v1/recommend -H 'Content-Type: application/json' -d '{
  "scenario": {
    "climate": {"hot_month_max": 33.5, "extreme_min": 6, "annual_rain": 1150},
    "traffic": "特重", "layer": "上面层", "thickness_cm": 4,
    "distress": [{"type": "rutting", "severity": "重"}],
    "constraints": {"cost_priority": "中", "carbon_priority": "中"}
  },
  "top_k": 3,
  "baselines": [{"modifier": "SBS", "dose": 4.5, "gradation": "SMA-13", "anti_strip": 1}]
}'
```
