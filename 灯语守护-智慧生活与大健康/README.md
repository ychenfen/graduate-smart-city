# 灯语守护——基于居家水电数据无感感知的独居老人安全预警系统

第十二届中国研究生智慧城市技术与创意设计大赛 · 定向赛道-智慧生活与大健康

不给老人装任何设备，只读家里已有的智能电表和远传水表每 15 分钟的读数，为每位老人学出个人作息基线，识别“该有动静却没有动静”的反常时刻（长时间无活动、夜间灯亮无人操作、电磁炉干烧、持续用水、起夜增多、作息偏离），先由 AI 外呼确认平安，必要时通知家属和网格员上门。

## 原型测试结果（模拟数据，留出测试集 100 户 × 62 天，团队自测）

六类危险事件 163 起全部检出，98.8% 达到紧急级，中位检出时间 1.15 小时；需人上门的误报 0.068 次/户·月，关注级误报 1.17 次/户·月（大多由自动外呼消化）；每户每 15 分钟计算约 7 微秒。对照的固定阈值规则检出率 65.0%、中位 7.9 小时、紧急误报 4.17 次/户·月。去掉个人基线后检出率降到 72.4%，只用电表时降到 63.8%。慢变化类事件（连续起夜 69.2%、作息偏离 75.0%）检出率较低，定位为提醒关注。
